# 0011 — Do not vendor the disease data; fetch with a required checksum, and generate synthetic fixtures

## Status

Accepted, 2026-09-17. **Ruled by the project owner.**

## Context

`hgps_main_data/data/index.json` declares the IHME disease data as **CC BY-NC-ND 4.0** —
non-commercial, **no derivatives** — which is materially more restrictive than the BSD-3-Clause
licence on the repository containing it. The UN demographic data is under a Creative Commons licence
of its own.

The earlier rewrite vendored a partial copy of the data tree with **no provenance for any of it**
(audit R-09 and `07-rewrite-data-examples.md`), which is both a licensing problem and an integrity
problem: nothing records which release those CSVs came from.

Against that: the baseline cannot run offline at all, every example points at a release URL, and
that is why its own 35 FINCH tests skip (B-11). Some offline capability is needed for CI.

Upstream also pins **five mutually exclusive data releases** across six examples (D-04), and nothing
records which release the local `hgps_main_data` working copy corresponds to.

## Decision

Ruled by the project owner:

- **Do not vendor the CC BY-NC-ND disease data.** Data is fetched on demand from a release URL with
  a **required** SHA-256 checksum, and cached content-addressed at
  `<cache>/data/<sha[0:2]>/<sha[2:]>/`. A checksum mismatch is an error naming both hashes. A URL
  or zip source without a checksum is a config error.
- **Ship a small synthetic data pack** under `tests/fixtures/` — a few diseases, one country, a
  short horizon — in exactly the layout the real data uses, generated by `tools/gen-fixtures`, with
  a `SYNTHETIC.md` recording that the numbers are invented, how they were generated, and that they
  must never be used for analysis.
- A local directory remains a first-class data source, so a developer with `hgps_main_data` on disk
  needs no network.

## Alternatives

- **Vendor the real data**, as the earlier rewrite did. Redistributing a no-derivatives dataset from
  a differently-licensed repository, with no provenance, is the thing the audit flagged.
- **Fetch without a checksum**, as a URL without `data.checksum` would allow upstream. Unverified
  model inputs are not acceptable provenance for numbers that inform policy.
- **Vendor a real subset.** A subset of a no-derivatives dataset is a derivative.

## Consequences

A first run against real data needs the network, and the cache makes later runs local. Tests that
need data use the synthetic pack, so a test's numbers are never evidence about the real world — the
fixture generator's docstring says so, and the equivalence harness against real data is what
provides that evidence instead. Fetching is delegated to `curl` and `unzip` (ADR 0014).
